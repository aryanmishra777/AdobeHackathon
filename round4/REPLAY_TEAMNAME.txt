TEST_STEPS:
 1. Install the submitted skills where the harness discovers them (macOS/Linux):

      mkdir -p ~/.claude/skills
      cp -r brand-ai-readiness-audit/skills/* ~/.claude/skills/

    Windows PowerShell:

      New-Item -ItemType Directory -Force "$HOME\.claude\skills"
      Copy-Item -Recurse -Force "brand-ai-readiness-audit\skills\*" "$HOME\.claude\skills\"

 2. Start Claude Code in an empty working directory and give it this prompt,
    verbatim (no flags, no file paths -- the harness selects the entrypoint skill
    from its description alone):

      audit https://www.grammarly.com/

    If your harness does not activate the skill from that alone, the explicit
    form is equivalent and was used in development:

      audit https://www.grammarly.com/ for AI discoverability and engagement

 3. The agent activates audit-orchestrator (declared entrypoint in
    marketplace.json). It runs site-evidence-collector exactly once -- one
    polite, robots-respecting crawl into .audit/www.grammarly.com/run-01/ --
    then dispatches the six analysis skills over that one bundle, merges the
    candidates with audit-orchestrator/scripts/merge_findings.py, applies the
    severity rubric and false-positive gates, and writes the report. Findings
    appear in report.md grouped by mechanism, each carrying its evidence, the
    bundle files it came from, a copy-pasteable verification command, and a fix
    with an owner and an effort estimate.

NOTES_ON_DETERMINISM:
                  Page sampling is a pure function of the site: home page first,
                  then sitemap entries in file order, then breadth-first with
                  section round-robin. No randomness and no time-dependent
                  ordering, so the same site yields the same sample. What can
                  differ between your replay and ours is the site itself (it is
                  live), and the wording a different model chooses for the
                  model-judged checks. The deterministic findings, their
                  evidence and their severities should match.
